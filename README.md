# Учебный проект №3 "RSS агрегатор" в программе "Фронтэнд-разработчик"
Реализован сервис для агрегации RSS-потоков. Он позволяет добавлять неограниченное количество RSS-лент, сам их обновляет и добавляет новые записи в общий поток.

## Описание. Использование и работа
* Введите в строку поиска валидный адрес RSS-ленты. Нажмите кнопку "Добавить". 
* Если адрес не содержит валидный URL или валидный RSS, появится соответствующая ошибка.
* Если лента ранее уже была добавлена, появится соответствующее сообщение.
* Так же отображаются ошибки сети.
* Если в адресе нет ошибок и он ранее не был добавлен, то на экране появится список фидов (RSS-ленты на которые вы подписались) и список постов каждого потока.
* При нажатии на каждый пост открывается новая вкладка с содержимым поста, а ссылка помечается как прочитанная.
* Так же доступен предпросмотр постов. При нажатии на кнопку "Просмотр" открывается модальное окно с названием новости и ее описанием.
* Раз в 5 секунд происходит обновление постов по каждому добавленному фиду.

## В работе над проектом были использованы:
* Vite с шаблоном Vanilla - сборщик фронтенда
* Bootstrap - html/css фреймворк
* Eslint - для анализа качества кода
* yup - для валидации данных формы. В том числе yup.setLocale() для настройки сообщений
* on-change - для обновления отображаемого контента
* i18next - библиотека для вывода текстов интерфейса
* Axios - библиотека для выполнения http-запросов
* DOMParser - механизм с помощью которого можно парсить RSS
* SetTimeout - для обновления контента раз в 5 секунд
